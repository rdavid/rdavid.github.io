== About

The {url-pages}[website] showcases the open source projects of
{url-cv}[David Rabkin].
Each project appears as a card with its logo, name, and short description.
A card opens the project's GitHub Pages site.
The site is plain HTML and CSS, with no build step and no JavaScript.
Its colors come from the {url-zenburn}[Zenburn] scheme.
